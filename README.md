# 🎓 고등학생 맞춤형 진로 탐색기 (Career Pathfinder)

고등학생이 자신의 교과목 선호도(1~5점)를 바탕으로 규칙 기반(Rule-based) 알고리즘을 통해 교과목 선호도 입력을 바탕으로 점수가 높은 2가지 관심 진로/직업을 탐색하고, 관련 학과 및 고교 학습 로드맵을 리포트(PNG/PDF)로 저장할 수 있는 단일 페이지 웹 애플리케이션(SPA)입니다.

---

## 🌟 주요 기능

1. **직관적인 별점 평가 UI:**
   - 국어, 수학, 영어, 한국사, 사회탐구, 과학탐구, 정보/코딩, 기술·가정, 미술/음악/체육, 제2외국어 등 10개 고교 표준 교과목군에 대한 1~5점 별점 평가

2. **사용자 직접 과목 추가 (Custom Subject Entry):**
   - 학생이 원하는 세부 과목을 직접 입력하고 6개 진로 계열(인문사회, 자연과학/공학, IT/소프트웨어, 예체능, 의약/바이오, 경영/경제) 중 하나를 필수 지정하여 추가

3. **투명하고 설명 가능한 추천 알고리즘 (Rule-based 2-Tier Engine):**
   - 1단계: 6개 계열별 가중치 합산 점수 및 동점자 처리 규칙으로 상위 2개 계열 선출
   - 2단계: 계열 내 직업별 세부 적합도 가중치(`subjectAffinity`)를 기반으로 최고 적합 직업 선출 (난수 미사용, 100% 결정론적 계산)

4. **상세 결과 카드 & 세션 상태 보존:**
   - Top 2 진로 카드에 주요 업무, 관련 대학 학과, 권장 고교 학습 과목, 추천 이유 및 공식 출처 링크 노출
   - '뒤로 가기 / 점수 수정' 클릭 시 기존 평가 별점 및 추가 과목 리스트가 초기화되지 않고 유지

5. **개인화 리포트 다운로드 (PNG / PDF):**
   - 학생 이름/닉네임 입력 유효성 검증 모달 제공
   - 이미지 파일(PNG) 및 문서 파일(PDF) 선택 다운로드 기능 지원

## 🚀 실행 방법

### 방법 1: 웹 브라우저 직접 실행
1. 저장소를 클론(Clone)하거나 다운로드합니다.
2. `index.html` 파일을 크롬(Chrome), 엣지(Edge) 등의 웹 브라우저에서 직접 더블 클릭하여 실행합니다.

### 방법 2: 로컬 웹 서버 실행
```bash
# Node.js 패키지 실행 (http-server 이용 시)
npx http-server . -p 8080
```
브라우저에서 `http://localhost:8080` 접속
